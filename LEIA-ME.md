# DuckDB Masterclass — Edição Mentoria (2026)

## Como estudar
1. Abra os notebooks na ordem 01–14. Execute as células sequencialmente em um ambiente virtual com `duckdb` e `pandas` instalados.
2. Antes de cada laboratório, preveja o resultado; depois, interprete-o.
3. Resolva os desafios antes de buscar exemplos prontos; traga dúvidas para a aula com a mentora.
4. Consulte `Originais/` quando quiser comparar a edição anterior.
